# Милые дела — Telegram Mini App

Нежное девчачье приложение внутри Telegram для ежедневных задач, списка покупок и вишлиста.

## Возможности

- **Задачи** — добавьте свои ежедневные дела, приложение запомнит их и предложит в другие дни
- **Повтор по дням недели** — задачи, которые нужно делать регулярно (пн, ср, пт и т.д.)
- **Список покупок** — отдельная вкладка для покупочек
- **Вишлист** — желаемые вещи с приоритетом и ссылкой на товар
- **Переключатель темы** — светлая / тёмная, нежные розово-голубые цвета
- **Без сервера** — данные хранятся локально в браузере (localStorage)

## Стек

- Vanilla JS (без фреймворков и сборщика)
- CSS с цветовыми токенами (розовый, нежно-голубой, циан)
- Telegram Web App API

## Деплой на GitHub Pages (бесплатно, без сервера)

1. Создайте публичный репозиторий на GitHub, например `task-manager-telegram`.
2. Загрузите файлы:

```bash
git init
git add .
git commit -m "feat: initial Telegram Mini App"
git branch -M main
git remote add origin https://github.com/ВАШ_НИК/task-manager-telegram.git
git push -u origin main
```

3. На GitHub откройте **Settings → Pages → Build and deployment → Source** → выберите ветку `main`, папку `/ (root)`, нажмите **Save**.
4. Сайт будет доступен по `https://ВАШ_НИК.github.io/task-manager-telegram/`.

## Привязка к боту через @BotFather

1. Напишите боту **@BotFather** в Telegram.
2. Команда `/newbot` → придумайте имя и username бота.
3. Команда `/newapp` → выберите своего бота, укажите:
   - **Web App URL**: `https://ВАШ_НИК.github.io/task-manager-telegram/`
   - название, описание, иконку 192×192
4. @BotFather выдаст ссылку вида `t.me/username_бота/app` — откройте её в мобильном Telegram.

**Важно:** URL Mini App должен быть по HTTPS (GitHub Pages даёт это автоматически).

## Хранение данных

Все данные (задачи, покупки, вишлист, тема) хранятся в `localStorage` браузера на вашем устройстве. При смене телефона или очистке кэша Telegram данные сбросятся — бэкенда нет.
